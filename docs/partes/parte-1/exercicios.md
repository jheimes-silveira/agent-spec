# Exercícios — Parte I

1. **(Ambiguidade)** Reescreva a instrução *"melhore a tela de login"* eliminando o máximo de ambiguidade possível. Liste pelo menos **4 suposições implícitas** que ela esconde.
2. **(Princípios)** Para cada situação, diga qual princípio cardeal está em jogo:

   * a. O gate recebe só o diff, não o repositório inteiro.
   * b. Uma task simples roda em Sonnet, não em Opus.
   * c. Uma magic string num teste vira dívida anotada em vez de reprovar.
3. **(Rastreabilidade)** Para a US *"Como usuário, quero recuperar minha senha por e-mail"*, escreva **2 CAs** e **1 CT** para cada CA.
