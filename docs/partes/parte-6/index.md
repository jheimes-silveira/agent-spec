# Parte VI — Qualidade de testes

> **A pergunta desta parte:** um teste verde prova que o código funciona — ou só que o teste foi escrito para passar?
>
> **Analogia âncora:** o teatro de testes — uma suíte toda verde que não pega bug nenhum é como um aluno que decorou a prova sem entender a matéria.

Quando uma IA escreve testes, ela tende a produzir o que **parece** teste: muito mock, asserção vaga, zero caso negativo. Esta Parte apresenta a doutrina que separa teste real de teatro — as Iron Laws, as famílias de antipadrões e os 7 gates que cada teste atravessa antes de ser aceito.
