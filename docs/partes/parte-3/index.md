# Parte III — Escolhendo o caminho: os quatro frameworks

> **A pergunta desta parte:** se toda feature passasse pelo mesmo cerimonial, metade seria over-engineering e a outra metade, under-engineering. Como escolher o peso certo para cada mudança?
>
> **Analogia âncora:** o veículo certo para a distância — ninguém pega um caminhão para ir à padaria, nem uma bicicleta para mudar de cidade.

O framework reconhece que features têm tamanhos diferentes. Forçar todas pelo mesmo pipeline gera desperdício de um lado e risco do outro. Esta Parte mostra os **quatro caminhos** — do spike descartável ao SDD completo — e como decidir entre eles **antes** de escrever a primeira linha.
