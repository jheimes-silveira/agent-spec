# Exercícios — Parte VII

1. **(5 critérios)** Para cada decisão, diga se vira ADR e qual critério a derruba (se algum):

   * a. "Neste endpoint específico, ordenamos a lista por data desc."
   * b. "Todo acesso a banco passa pelo Repository; injeção direta de pool é proibida."
   * c. "Usamos a única biblioteca de HTTP disponível na linguagem."
2. **(Lifecycle)** Uma ADR foi substituída por outra. Qual o status dela, ela é apagada, e os gates passam a lê-la?
3. **(Compliance)** Por que "a camada de domínio não pode importar a de infra" fica no Gate 2, enquanto "tags `json:` devem estar em inglês" pode ser pego no Gate 1?
