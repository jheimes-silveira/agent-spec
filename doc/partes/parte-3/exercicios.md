# Exercícios — Parte III

1. **(Escolha de caminho)** Para cada cenário, diga o caminho recomendado (Conversa direta / TaskCard / miniSpec / SDD) e justifique em uma frase:

   * a. Corrigir um typo numa mensagem de erro de uma tela.
   * b. Adicionar "exportar relatório em PDF" com novo endpoint, serializador e tela.
   * c. Testar se uma biblioteca de gráficos atende, sem compromisso de manter o código.
   * d. Construir um subsistema de cobrança com 6 user stories e integração com gateway externo.
2. **(Promoção vs degradação)** Você começou uma feature como TaskCard e, ao detalhar, percebeu que são 3 tasks com dependência entre si. Qual o custo de **promover** para miniSpec e por que ele é menor do que o risco de seguir como TaskCard?
3. **(Variante)** Numa miniSpec de frontend, por que a skill `agent-spec-minispec-generate-scope` confirma a variante (web/mobile/backend) via `AskUserQuestion` mesmo havendo `tech-alignment.md`?
