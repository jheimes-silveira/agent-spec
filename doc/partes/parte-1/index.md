# Parte I — Por que especificar antes de codar

> **A pergunta desta parte:** se LLMs escrevem código, por que eu deveria escrever um documento antes?
>
> **Analogia âncora:** a planta antes da parede.

Mudar a planta no papel custa um apagador; derrubar uma parede já levantada custa uma semana. O `agent-spec` empurra o máximo de decisões para a fase "papel" — e esta Parte explica o porquê de cada uma das quatro convicções operacionais.
